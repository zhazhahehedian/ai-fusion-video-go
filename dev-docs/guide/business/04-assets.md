# 资产

资产属于项目，子资产属于资产。读取和修改都先确认个人项目拥有者。

## 删除

删除主资产时，先软删全部子资产，再软删主资产。每一行一条 revision。这样列表里不会留下没有主资产的子资产。

删除子资产时，如果它的图片地址和主资产封面相同，封面被清空，主资产版本加一。封面清空的 `changedFields` 是 `coverUrl`。没有动封面时，主资产修订的字段是 `items`，用来表示子集合变了。这和 Java `detachItem` 一致：封面命中才改封面，父行总是被碰到。
