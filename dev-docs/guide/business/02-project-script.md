# 项目、剧本、分集与场次

## 项目

创建项目是一条资源命令。它写入 `afv_project`，并创建一条空剧本，使项目一开始就有工作区。项目 `version` 从 0 开始。只有个人拥有者能创建在自己的名下。

Java 创建项目还会初始化成员、分镜等工作区对象。Go 的项目命令目前保证项目和剧本。分镜要单独创建。

## 剧本

一个项目当前按一条剧本使用。读取入口是 `GET /api/script/project/{projectId}`。

修改剧本字段走 `PATCH`，必须带 `version`。版本不符返回 409。替换原文是另一条命令 `REPLACE_SCRIPT_SOURCE`：清空解析结果，把 `rawContent` 换成新原文，`parsingStatus` 回到 0，`totalEpisodes` 回到 0。

替换原文会软删该剧本下的全部分集和场次。原因是旧结构属于上一份原文，留着会和新原文矛盾。每一行都写 revision，避免只在剧本上看到「内容变了」却不知道哪些子行被删了。Java 的原文替换同样清掉派生树。

## 分集与场次

剧本分集属于剧本，场次属于分集。创建时要带父版本，防止父行已经变化还往旧结构里插入。集号在同一剧本内不能重复。

删除分集：先按 id 锁定并软删全部场次，每行一条 revision，再软删分集，然后按剩余分集数回写剧本的 `totalEpisodes` 并增加剧本版本。

删除场次：只软删这一场，并回写分集的场次数。不删除分集。

前端一次调用删除分集。确认文案说明子场次会一起消失，所以服务端级联，而不是让前端逐条删。
