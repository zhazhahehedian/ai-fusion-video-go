# 技术债

长期说明见 `dev-docs/guide/`。下表只保留这次提交还没做的项。

| 项 | 原因 |
|---|---|
| 不调用图片或视频供应商 | 没有供应商配置表，也没有对象存储。成功地址是 `stub://`，表示队列写回已经发生 |
| 不按 `ai_model` 算并发，也不校验 `modelId` | 本库没有模型表。`modelId` 只记在任务和作业上，额度仍是固定 8 |
| 带 `workflowVersionId` 直接拒绝 | 没有 ComfyUI 工作流表。不能把这类请求标成 stub 成功 |
| 没有 `POST /{taskId}/cancel` 和 `GET /{taskId}/execution` | Java 用它们停远端作业和查看执行。这次只接通提交和写回 |
| 一次提交只有一个远端作业 | 没有供应商协议给出的批量大小。条目都挂在这一条作业上 |
| `count` 最大 16，提示词最长 65535 | 与本库创建接口和 `TEXT` 列一致。Java 提交校验是 32 和 100000 |
| 省略水印、配音时不填模型默认值 | Java 按模型配置补 `false` 或 `true`。没有模型配置就不补 |
| 带 `teamId` 返回 409 | 会话里没有当前团队。不能把团队编号当成已经校验过的上下文 |
